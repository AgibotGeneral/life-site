# LIFE — Learning to Live

Project page for **Learning to Live: A Step Toward Lifelong Embodied Intelligence**.

- Paper: [arXiv:2611.00180](https://arxiv.org/abs/2611.00180)
- Code: [AgibotTech/LIFE](https://github.com/AgibotTech/LIFE)
- Models: [RoboBeats-0.8B](https://huggingface.co/superbigsaw/RoboBeats-0.8B) · [RoboBeats-2B](https://huggingface.co/superbigsaw/RoboBeats-2B) · [RoboBeats-4B](https://huggingface.co/superbigsaw/RoboBeats-4B)

The site is static: `index.html` and `assets/`, served by GitHub Pages. To preview it locally, serve the folder with any static server that supports HTTP range requests, for example:

```sh
npx http-server . -p 8080
```
